# 系列编排说明

每个 .yaml 对应一个系列，文件名 = src/assets/photos/ 下的文件夹名。

照片用编号引用：`08` 表示本系列的 `<系列>-08.jpg`；也可以写完整名如 `amber-29` 跨系列引用。

## 排版类型（每行一种）

| 写法 | 效果 |
|---|---|
| `full: 03` | 通栏，铺满屏幕宽度（适合横图、全景） |
| `wide: 03` | 大图，左右留边 |
| `center: 03` | 居中单张，限制高度、四周留白（适合竖图、方图） |
| `left: 03` / `right: 03` | 单张偏左 / 偏右，杂志感 |
| `row: [03, 04]` | 多张并排，自动等高对齐（2–4 张） |
| `stack: [03, 04, 05]` | 多张上下紧贴，适合连拍序列 |

## 其他字段

- `place`：拍摄地点（可选，显示在章节标题旁）
- `order`：相册顺序（数字小的在前）
- `cover`：封面
- `backdrop`：垫在相册背景里的照片（低透明度 + 视差），不写就用封面
- `tint`：背景的色彩倾向（颜色值，如 "#2f78e0"），背景照片会被染成这个色调
- `hidden`：不展示的照片
- 没出现在 yaml 里、也不在 hidden 里的照片，会自动排在页面最后
- 每个 group 之间留大段空白，用来区分同一系列里的不同组
